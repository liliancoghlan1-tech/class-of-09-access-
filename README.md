# class-of-09-access-
A mod that makes class of 09 accessible to the blind.

class of 09  is a visual novel in which you play the anime girl and  get to brutally reject the scores of bizarre suitors who would be the protagonist if this were a different game  

you play through voice acted scenes while making choices in order to achieve the games many endings, and now, it is fully accessible. 

this game was built in REN'PY, which should make it accessible by default,  but it does  not,  owing  to a bizarre bug that would cause the self voicing feature to automatically skip every single line of spoken dialogue, which is like the whole point of the game. 

I have now  fixed  this  issue  by allowing the game to hook into popular screen reader NVDA.  i  also did a little tinkering with the game to allow the main menu to be easily navigable with arrow keys so no mouse input is required. 

some menus are a little tricky, but they are largely inconsequential to the game so don't worry, they  won't affect your experience. 

hope you enjoy.
